# 07 · 核验一条分支

## 为什么必须核验

格式号填对了，只说明**游戏肯加载这个包**；包里的文件**路径**对不对，才决定**内容有没有生效**。
资源包是被动覆盖：路径错了不报错、不崩溃、日志不提示，只是你改的那张贴图没出现。
跨版本时这最容易发生（见 [06-各版本路径变化对照](06-各版本路径变化对照.md)）。

## 怎么跑

脚本在下面（只依赖 Python 标准库）。存到仓库外，例如
`%LOCALAPPDATA%\Temp\fpp-verify\check_branch.py`，然后**在仓库根目录**运行：

```sh
# 核验当前检出的分支（目标版本填它自己的 MC 版本）
git switch mc1.16.5
python "$LOCALAPPDATA/Temp/fpp-verify/check_branch.py" 1.16.5

# 给新分支做工作量预估：内容来自 1.16.5 时代的 master，目标是 1.21.11
git switch mc1.21.11
python "$LOCALAPPDATA/Temp/fpp-verify/check_branch.py" 1.21.11 --baseline 1.16.5
```

它会：下载并 **sha1 校验**该版本的官方客户端 jar（缓存在系统临时目录，反复用）→ 读当前分支的
`FPP/pack.mcmeta` → 把包里每个文件与该版本原版资源清单逐个对照。

`--baseline` 默认 `1.16.5`（当前内容所处的年代），用来判断"老路径"；内容年代与目标一致时
可以写 `--baseline none` 关掉这一栏。

## 输出怎么读

```
包内文件 2717 个（含 .mcmeta 68 个）
  该版本原版会读                    1980
  该版本不读                         735
    ├ 旧路径残留（包里有能用的一份）      3  无害
    ├ 原版把同名资源挪了位置             0  ← 先查这些
    ├ 老路径（原版 1.16.5 有、该版本没有）  0  ← 再查这些
    └ 自建资源（原版从来没有过）        732  无害
  .DS_Store 残留                      0
```

| 分类 | 含义 | 要做什么 |
| --- | --- | --- |
| 原版会读 | 路径正常，包的内容生效 | — |
| **原版把同名资源挪了位置** | 该版本原版里有同名资源，只是换了目录，而且包里**没有**能用的另一份 | **改路径**（照 [06](06-各版本路径变化对照.md)） |
| **老路径** | 该路径在基线版本（默认 1.16.5）原版里有、目标版本没有 | 目标**比基线新** → 要改；目标**比基线老** → 白带，别动 |
| 旧路径残留 | 老路径上的一份没用，但包里有同一资源的新路径一份 | 不管（可选清理） |
| 自建资源 | 任何原版都没有过这个路径（自写模型、拆分的变体帧） | 不管 |

判读要点：

- **`.png.mcmeta` 不算"没生效"**：原版不带 `.mcmeta`，脚本会看它描述的贴图在不在，不会误报。
- **"同名资源"提示只是同名，不保证是同一张图**（例：床贴图 `entity/bed/black.png` 会被提示到
  `entity/equipment/llama_body/black.png`，那其实是骆驼装备）。**它是线索，不是结论** ——
  真要确认原版把资源挪到哪，查该版本的迁移说明或直接翻客户端 jar。
- 真正要动手的只有**"挪了位置"**和**（目标更新时的）"老路径"**两栏。

## 两条已建分支的基线（2026-10-10 实测）

| | `mc1.15.2` | `mc1.16.5`（= master 当前内容） |
| --- | --- | --- |
| 包内文件 | 2571（含 80 个 `.mcmeta`） | 2717（含 68 个 `.mcmeta`） |
| 原版会读 | 1981 | 1980 |
| 不读 | 588（旧路径残留 2 + 自建资源 586） | 735（旧路径残留 3 + 自建资源 732） |
| **挪了位置 / 老路径** | **0 / 0** | **0 / 0** |
| `.DS_Store` | 0 | 0 |

结论：两条线**没有需要修的失效路径**。以后改动后重跑，那两栏仍应是 0；出现在这两栏就按 06 处理。

## 常见问题

| 现象 | 原因 |
| --- | --- |
| 游戏里显示"不兼容" | `pack.mcmeta` 的 `pack_format` 与该 MC 版本不符（见 [05](05-pack.mcmeta-与格式号.md)） |
| 装了但贴图没变 | 大概率是路径变了（本页"挪了位置/老路径"两栏）；也可能是 zip 里多套了一层目录 |
| zip 结构 | 根目录必须直接是 `pack.mcmeta` + `assets/`，**不能**再套一层 `FPP/` |
| 输出中文乱码 | 脚本已 `sys.stdout.reconfigure(encoding="utf-8")`；改脚本时请保留这一行 |
| 想核验还没建成分支的内容 | 把要验的目录放到临时文件夹、内部有 `FPP/`，在该目录下运行脚本即可 |

## 脚本

```python
"""核验"当前检出的分支"是否真的对得上某个 MC 版本。

用法（在仓库根目录）：
    python check_branch.py 1.16.5                     # 核验当前分支
    python check_branch.py 26.3 --baseline 1.16.5     # 额外找出"老路径"（默认基线就是 1.16.5）
做三件事：下载并校验官方客户端 jar、读该分支的 pack.mcmeta、逐个文件对照原版资源清单。
"""
import collections, hashlib, json, sys, tempfile, urllib.request, zipfile
from pathlib import Path

sys.stdout.reconfigure(encoding="utf-8")   # Windows 默认 cp936，中文会乱码
args = sys.argv[1:]
if not args:
    sys.exit("用法: python check_branch.py <目标MC版本> [--baseline 1.16.5|none]")
ver = args[0]
baseline = args[args.index("--baseline") + 1] if "--baseline" in args else "1.16.5"
if baseline == "none":
    baseline = None
root = Path("FPP")
pack = json.loads((root / "pack.mcmeta").read_text(encoding="utf-8"))["pack"]
print(f"分支声明: pack_format={pack['pack_format']}  version={pack['version']!r}")

cache = Path(tempfile.gettempdir()) / "fpp-verify"
cache.mkdir(exist_ok=True)


def jar_for(v):
    """取该版本官方客户端 jar（缓存在系统临时目录；sha1 来自 Mojang 官方清单）。"""
    jar = cache / f"client-{v}.jar"
    if not jar.exists():
        mf = cache / "version_manifest_v2.json"
        if not mf.exists():
            urllib.request.urlretrieve(
                "https://launchermeta.mojang.com/mc/game/version_manifest_v2.json", mf)
        man = json.loads(mf.read_text(encoding="utf-8"))
        meta = json.loads(urllib.request.urlopen(
            next(x["url"] for x in man["versions"] if x["id"] == v)).read())
        c = meta["downloads"]["client"]
        print(f"下载 {v} 客户端 {c['size'] / 1048576:.1f} MB …")
        urllib.request.urlretrieve(c["url"], jar)
        assert hashlib.sha1(jar.read_bytes()).hexdigest() == c["sha1"], "sha1 校验失败"
    return set(zipfile.ZipFile(jar).namelist())


zset = jar_for(ver)
baseline_paths = jar_for(baseline) if baseline else set()
files = {p.relative_to(root).as_posix(): p for p in root.rglob("*") if p.is_file()}
assets = sorted(r for r in files if r.startswith("assets/minecraft/"))


def base(rel):
    """foo.png.mcmeta → foo.png：动画元数据本身原版不带，要看它描述的贴图在不在。"""
    return rel[:-7] if rel.endswith(".mcmeta") else rel


def key(rel):
    """(层级, 基名) —— 判断"同名资源是否只是换了位置"，且不允许跨层级误配。

    层级取 assets/minecraft/ 之后的**目录**（不含文件名）的前两段：
    textures/entity/a.png 与 textures/entity/b/a.png 都算 textures/entity；texts/credits.txt 算 texts。
    """
    dirs = rel.split("/")[2:-1]
    return ("/".join(dirs[:2]), Path(rel).name.split(".")[0])


read = [r for r in assets if base(r) in zset]
dead = [r for r in assets if base(r) not in zset]
read_keys = {key(r) for r in read}
legacy = [r for r in dead if key(r) in read_keys]           # 包里有能用的一份，这个是旧路径残留
rest = [r for r in dead if key(r) not in read_keys]
vanilla = collections.defaultdict(list)
for n in zset:
    vanilla[key(n)].append(n)
# 原版把同名资源挪到了别处（如 1.21.2 的实体贴图搬家）→ 一定失效
moved = [r for r in rest if vanilla.get(key(r))]
# 该路径在原版 1.16.5（这个包内容所处的年代）里存在、目标版本已经没有 → 大概率失效
former = [r for r in rest if r not in moved and r in baseline_paths]
# 任何原版都没有过这个路径 → 包自建资源
own = [r for r in rest if r not in moved and r not in former]

print(f"\n包内文件 {len(files)} 个（含 .mcmeta {sum(1 for r in files if r.endswith('.mcmeta'))} 个）")
print(f"  该版本原版会读                {len(read):>5}")
print(f"  该版本不读                    {len(dead):>5}")
print(f"    ├ 旧路径残留（包里有能用的一份） {len(legacy):>5}  无害")
print(f"    ├ 原版把同名资源挪了位置       {len(moved):>5}  ← 先查这些")
if baseline:
    print(f"    ├ 老路径（原版 {baseline} 有、该版本没有） {len(former):>5}  ← 再查这些")
print(f"    └ 自建资源（原版从来没有过）    {len(own):>5}  无害")
print(f"  .DS_Store 残留                {sum(1 for _ in root.rglob('.DS_Store')):>5}")
for title, group in (("原版把同名资源挪了位置", moved),
                     (f"老路径：原版 {baseline} 有、该版本没有", former)):
    if group:
        print(f"\n{title}: {len(group)} 个（只列前 15 个）")
        for r in group[:15]:
            hint = "、".join(vanilla[key(r)][:2]) if vanilla.get(key(r)) else ""
            print(f"  {r}" + (f"\n      该版本原版的同名资源（只是同名提示，不保证同一张图）: {hint}" if hint else ""))
```
